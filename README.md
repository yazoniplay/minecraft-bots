# Minecraft AI Army — NOUR vs CHAOS

A standalone **Paper 1.21.4 plugin** that deploys two AI-controlled factions directly inside your Minecraft server. No Node.js controller, external API, bot accounts, or school-PC process is required for the plugin mode.

## What it does

- **NOUR and CHAOS factions** with visible faction names and persistent entity tags.
- **One-command deployment:** spawn both factions or either faction independently.
- **Squad targeting:** units scan nearby living entities, identify opposing army units, and focus nearby enemies using Minecraft's native mob pathfinding and combat AI.
- **Specialist units:** ranged Pillagers and frontline Vindicators.
- **Enhanced combat stats:** increased health, movement speed, armor, attack damage, knockback resistance, and fire resistance.
- **Faction-safe targeting:** army units do not target members of their own faction.
- **NOUR fortress command:** generate a stone-brick perimeter fortress with four raised towers.
- Configurable squad size and a hard per-faction spawn cap.

This is a server-side NPC army. Units are Minecraft mobs with enhanced AI, **not real player accounts**. They cannot use player chat or player-only actions, and the castle is generated by the plugin rather than constructed block-by-block by NPCs.

## Requirements

- Paper 1.21.4
- Java 21
- Operator permission or `minecraftarmy.admin`

## Build the plugin

The GitHub Actions workflow **Paper plugin build** compiles the JAR automatically.

1. Open the repository's **Actions** tab.
2. Open the latest successful **Paper plugin build** run.
3. Download the `minecraft-army-paper-1.21.4` artifact and extract it.
4. Upload `MinecraftArmy.jar` into your server's `plugins/` folder.
5. Restart the Paper server.

The plugin creates `plugins/MinecraftArmy/config.yml` on first launch.

## In-game commands

Run these in-game:

| Command | Result |
|---|---|
| `/army spawn all` | Deploy NOUR and CHAOS |
| `/army spawn nour` | Deploy NOUR only |
| `/army spawn chaos` | Deploy CHAOS only |
| `/army status` | Count living units in each faction |
| `/army stop` | Remove all army units |
| `/army build castle` | Generate the NOUR fortress near you |

The spawn command needs a player location, so run it in-game rather than from the server console.

## Configuration

Edit `plugins/MinecraftArmy/config.yml`:

- `army.units-per-faction`: units to add each time a faction is spawned (default 6).
- `army.max-units-per-faction`: maximum active units per faction (default 24, hard-limited to 24).
- `army.target-range`: horizontal scan range for nearby targets (default 24).

Start with 4–6 units per faction. Large mob groups can create substantial server load, especially when many entities pathfind and fight at once. Increase gradually and monitor your server's TPS.

## Important limitations

- These are NPC mobs, not authenticated player clients.
- They use enhanced vanilla mob AI and faction target selection; they are not running a language model.
- Gathering, mining, crafting, diplomacy, long-term plans, player-like chat, and autonomous NPC construction are not implemented in this standalone plugin yet.
- The fortress command edits blocks directly in the world. Back up important builds before testing it.
- The plugin has been compiled in CI, but still needs a live Paper 1.21.4 server test.

Only install this on a server you own or have permission to modify.
